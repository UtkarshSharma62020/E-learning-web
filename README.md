To run this file,
open new terminal and write : git clone https://github.com/UtkarshSharma62020/E-learning-web.git
1) Delete the venv and create a new virtual env as, 'python -m venv venv' ,
2) then through 'command promt(not powershell) in vscode', write venv\Scripts\activate ,
3) then write 'pip install -r requirements.txt' ,
4) then make changes in settings.py as, DEBUG = 'True' and ALLOWED_HOSTS = ['127.0.0.1','localhost','*'] .
5) then write 'python manage.py runserver' .
